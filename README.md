# Student Management System

A Java-based Student Management System developed as a practical project while learning Core Java and Object-Oriented Programming.

The project is being developed progressively, with new Java concepts and features added version by version.

## 🚀 Project Overview

The Student Management System allows users to manage student records through a menu-driven console application.

### Current Features

- Add Student
- View Students
- Search Student
- Update Student
- Delete Student
- Student validation
- Duplicate USN prevention
- File-based data storage
- Recently added students tracking

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming
- Collections Framework

## 💡 Collection Design

Different Java collections are used for different purposes:

ArrayList → Store and display students
HashMap → Fast USN-based student lookup
HashSet → Prevent duplicate USNs
LinkedList → Track recently added students
## 🎯 Student Management

Users can:

Add a new student
View all students
Search using USN
Update student information
Delete a student
## 🛡️ Validation

The system includes:

Age validation
Duplicate USN validation
Student-not-found handling
Custom exceptions
## 💾 File Handling

Student data can be stored in a text file and loaded when the application starts.
